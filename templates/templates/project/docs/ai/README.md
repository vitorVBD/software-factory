# Contexto de IA do projeto

Estes documentos alimentam a Software Factory. Mantenha-os curtos, factuais, revisados e específicos deste repositório.

- `project-profile.md`: ficha geral e stack.
- `architecture.md`: módulos, fluxos e decisões arquiteturais.
- `business-rules.md`: regras de domínio documentadas.
- `design-system.md`: tokens e padrões de UI.
- `conventions.md`: padrões de código e scripts.
- `security-posture.md`: autenticação, autorização, dados e controles conhecidos.
- `quality-strategy.md`: testes e critérios de qualidade.
- `tasks/`: registros de trabalho e evidências.
- `templates/task/`: templates de documentação de tarefa.

Use `Confirmado no código`, `Documentado`, `Inferido` ou `Desconhecido`. Não armazene secrets, dados pessoais reais, tokens ou dumps.
