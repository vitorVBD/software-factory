# Implementation Prompt

O prompt deve ser específico, executável e auditável. Inclua contexto confirmado, objetivo, requisitos, regras, arquivos/componentes a inspecionar, plano incremental, padrões existentes a reutilizar, segurança, UX, testes, critérios de aceite e relatório final.

Não invente caminhos ou comandos. Quando não souber, instrua o Developer a inspecionar e descobrir. Não inclua instruções para ignorar testes, segurança, revisão ou aprovação humana. Gere `02-implementation-prompt.md`.
